КАК САМОЙ РАСКЛАДЫВАТЬ ПОМИДОРКИ, ЛИСТИКИ И КРУЖОЧКИ
В index.html сразу после <main id="top"> есть блок с комментарием «ДЕКОР».
Это отдельный слой поверх всей страницы. Декор НЕ находится внутри фотографии теплицы.

Каждый элемент выглядит так:
  <span class="page-decor decor-tomato" style="left:10%;top:25%"></span>

Меняйте только два значения:
  left — положение по горизонтали;
  top  — положение по вертикали.

Примеры:
  left:10%; top:20%;   — ближе к левому верхнему углу
  left:50%; top:50%;   — центр страницы
  left:90%; top:80%;   — ближе к правому нижнему углу

Виды декора:
  decor-tomato  — помидорка
  decor-leaf    — листик
  decor-circle  — кружочек

Чтобы добавить ещё один элемент, просто скопируйте любую строку <span> и поменяйте class, left и top.
Чтобы убрать элемент — удалите его строку.
Чтобы изменить размер, можно добавить например width:40px;height:40px в style.
Все элементы уже плавно двигаются с помощью CSS-анимации.

ВАЖНО ПРО ГЛАВНУЮ ФОТОГРАФИЮ
В hero больше НЕТ дополнительных HTML-помидоров и листьев поверх фотографии.
Файл assets/greenhouse-hero.png остаётся чистой фотографией теплицы.

КАК ПОМЕНЯТЬ ФОТО ТЕПЛИЦЫ
Замените assets/greenhouse-hero.png на новое изображение с тем же именем.

КАК ПОЗЖЕ ДОБАВИТЬ РОБОТА
В hero-scene в index.html можно добавить <img class="hero-robot" ...> поверх hero-photo.
Сам robot-full.png в hero не вставляется автоматически.

ЗАПУСК
